## 5. 模块设计（关键实现点）

### 5.1 baymax_pet.py — 大头窗
- `Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool | Qt.WindowDoesNotAcceptFocus`
- `setAttribute(Qt.WA_TranslucentBackground)` + 自绘 QLabel 显示透明帧
- 眨眼：QTimer 每 3s 触发一次"闭眼 2 帧 → 睁眼"微序列（复用 FSM 节奏）
- 悬停：重写 `enterEvent` → 徽章按钮淡入（QPropertyAnimation，150ms）；`leaveEvent` 且鼠标不在按钮上 → 淡出
- 拖动：重写 `mousePressEvent`/`mouseMoveEvent`，按住脸任意处拖动
- 右键菜单：关闭 / 打开面板 / 退出

### 5.2 baymax_panel.py — 面板窗
- 同样无边框+透明背景，QSS 圆角 30px、白色 90% 不透明（`rgba(255,255,255,0.9)`）
- 顶栏：状态区（情绪 | 记忆命中 | 最近动作），来源 bridge 信号
- 中间：左 QListWidget（💬聊天 / 🧠记忆 / ⏰提醒）+ 右 QStackedWidget
- 底部：⚙️ 按钮（开 settings_dialog）、🖌 拖动条（面板拖动）
- **弹出位置算法**：取大头全局位置 `mapToGlobal` → 与 `QScreen.availableGeometry` 比较四边剩余宽度/高度 → 选最大空间一侧；贴边时向内偏移 12px。面板不遮挡大头本身

### 5.3 panel_pages.py — 四页
| 页 | 组件 | 行为 |
|---|---|---|
| 聊天 | QTextBrowser + QLineEdit + 发送 | 每轮清空 TextBrowser，显示本轮对话（人话+工具动作），输入回车发送 |
| 记忆 | QTableView + QSqlQueryModel | 只读，列：内容/来源/重要性/时间；提供"刷新" |
| 提醒 | QTableWidget + 添加/删除 | 列：事项/时间/日期/频率/状态；添加走同一套相对日期换算 |
| 设置 | （弹窗） | 只编辑白名单提示词 |

### 5.4 chat_worker.py — 跨线程聊天
- `class ChatWorker(QThread)`：run() 调 `brain.ask_baymax_with_tools(user_text, on_chunk=...)`
- 信号：`chunk_signal(str)`（流式逐字 → 聊天页 append）、`done_signal(str)`、`emotion_signal(str)`、`action_signal(str)`
- 关键约束：**worker 只碰大脑，绝不碰 UI 控件**；UI 更新全走信号（Qt 自动排到主线程）
- 忙碌时发送键禁用（防并发）

### 5.5 bridge.py — 信号桥
- 单例 QObject，集中定义所有信号：`status_updated / memory_updated / reminder_updated / emotion_changed`
- 现有 `emotion_queue`/`action_queue` 泵（QTimer 200ms 轮询）→ 转成信号 → 面板顶栏
- 目的：未来加"麦克风/步数"等窗口功能，只加信号，不动页面

### 5.6 settings_dialog.py — 设置白名单
- config.py 新增：

```python
USER_TWEAKABLE_PROMPTS = {
    "招呼语": "……",   # 用户可改
    "安慰语气": "……",
}
# 核心提示词（人设全量 / Pass2 / 工具说明书）不在此区，UI 不暴露
```

- 设置页只读写 USER_TWEAKABLE_PROMPTS；核心提示词硬编码在 brain.py，UI 无入口

## 6. 里程碑与验收

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| **M1 大头**（半天） | 透明窗 + 眨眼轮播 + 拖动 + 右键菜单 | 桌面出现 320px 大白头，每 3s 眨眼一次，可拖动，右键可退出 |

| **M3 三页接大脑**（1 天） | 聊天流式 / 记忆只读 / 提醒管理 | 面板里能和大白聊天（流式打字）、能看记忆表、能增删提醒，与命令行版数据互通 |
| **M4 设置+打磨**（半天） | 设置页白名单 / 淡入淡出 / 空状态提示 | 设置页改招呼语生效；核心提示词无入口；全程 UI 不卡死 |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 跨线程卡 UI | worker 信号回主线程，禁用发送键防并发（M3 验收重点） |
| 白底抠图残留白边 | PIL 阈值 250 + 羽化 1px；预览验收 |
| 多屏/高分屏缩放 | 用 QScreen.devicePixelRatio 处理；先主屏验证 |
| 面板盖住大头 | 位置算法把大头自身 boundingRect 排除 |

## 8. 可扩展性约定

- 新页面 = QStackedWidget `addWidget` 一页，不动其他页
- 新窗口功能 = desktop/ 加 .py + bridge 加一个信号
- 新表情 = assets/pet/frames_pet 加序列 + FSM 表加一行
- 桌面级后续：麦克风唤醒（QThread worker）、系统托盘、开机自启——都在此壳上扩展
